🕌 Masjid Answer Service

A mosque community assistant API — announcements plus live prayer times, answered by AI in warm, simple Ghanaian English.

Status: Live x-api-key auth Multi-developer No fatwas

How it works

1. RegisterCreate your mosque once and get a mosqueId.
2. AnnouncePost Jumu'ah times, programs, fundraisers.
3. AnswerMembers ask questions — the AI replies using your announcements plus live prayer times for your city.

Authentication

Every request needs your Studio API key in the header. Don't have one? Get it free on the Studio API home page.

# every call carries your key
-H "x-api-key: YOUR_STUDIO_KEY"

1. Register a mosque

Creates your mosque and returns a mosqueId. The mosque belongs to your API key — only your key can announce or answer for it.

curl -X POST https://studio-api-nqpm.onrender.com/v1/masjid/register \
  -H "x-api-key: YOUR_STUDIO_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "mosqueName": "Masjid Al-Nur",
    "city": "Tarkwa",
    "whatsappAdminPhone": "+233500000000"
  }'

Response:

{
  "mosqueId": "msj_2e0c8768-...",
  "mosqueName": "Masjid Al-Nur",
  "city": "Tarkwa",
  "notice": "Keep this mosqueId. Only this API key can announce or answer for it."
}

2. Store announcements

Jumu'ah khutbah times, weekly programs, fundraisers, maulid dates — up to 1000 characters. The 10 newest are used when answering.

curl -X POST https://studio-api-nqpm.onrender.com/v1/masjid/announce \
  -H "x-api-key: YOUR_STUDIO_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "mosqueId": "msj_2e0c8768-...",
    "text": "Jumuah khutbah starts 12:30pm this week. Fundraiser for the new wudhu area after Asr on Saturday."
  }'

Response:

{ "announcementId": "ann_f52659c2-...", "mosqueId": "msj_...", "text": "...", "created_at": "2026-10-18T06:02:00Z" }

3. Answer a member's question

The member asks in plain language ("Please what time is Jumuah?"). The service fetches today's prayer times for your city from the Ilm API, adds your stored announcements, and an AI answers briefly and warmly.

curl -X POST https://studio-api-nqpm.onrender.com/v1/masjid/answer \
  -H "x-api-key: YOUR_STUDIO_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "mosqueId": "msj_2e0c8768-...",
    "question": "Please what time is Jumuah and is there any program this week?"
  }'

Response:

{
  "answer": "Hello! Jumu'ah this week: the khutbah begins at 12:30 pm, and the prayer will follow right after. After Asr on Saturday, we'll have a fundraiser for the new wudhu area. May your day be blessed!",
  "sources": {
    "prayerTimes": { "city": "Tarkwa", "date": "2026-10-19", "times": { "fajr": "...", "dhuhr": "...", "asr": "...", "maghrib": "...", "isha": "..." } },
    "announcementsUsed": [ { "id": "ann_...", "text": "Jumuah khutbah starts 12:30pm..." } ]
  }
}

Privacy between developers

Each mosque is bound to the API key that registered it. If another developer's key tries to touch your mosque — even to announce on it — they get a plain 404 mosque not found. The system never reveals that your mosque exists.

Religious safety

The assistant answers community questions (times, programs, general guidance) in simple, warm English. It is instructed never to issue fiqh rulings or fatwas — such questions are referred to a qualified scholar or the imam.
